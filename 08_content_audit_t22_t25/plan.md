# 实施计划

1. 从修正后的 6,602 个 family representatives 中提取 Topic 22 和 Topic 25，共 87 个规范化专利族。
2. 用 Publication No 连接原始专利文本，提取英文标题、摘要、第一权利要求、申请日、申请人和 IPC。
3. 用固定随机种子混排，生成不含 Topic、risk level、HMM、STM 和 family ID 的第一轮工作簿。
4. 预先随机抽取 18 条，重新编号并再次混排，生成延迟复审工作簿。
5. 把 Topic、family ID 和两轮编号映射只写入单独的 `DO_NOT_OPEN` 密钥文件。
6. 冻结编码规则和主要终点；所有不确定判断允许选择 `UNCLEAR`，禁止强行归类。
7. 用户完成两轮审查后，运行分析脚本：完整性核查、解盲、描述性比例、Wilson 95% CI、Topic 22/25 探索性 Fisher 检验、审查者内一致性。
8. 最终报告明确区分内容有效性、统计对比和 cascade 因果验证。

## 成功标准

- 第一轮恰好 87 个唯一专利族：Topic 22=49，Topic 25=38。
- 第一轮工作簿不泄露 Topic 或模型结果。
- 第二轮恰好 18 个唯一复审对象，不显示第一轮编号。
- 所有人工判定字段为空并配置有效下拉选项。
- 解盲文件与工作簿一一对应。
- 分析脚本在未完成数据上拒绝生成正式结论。
